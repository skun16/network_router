network_router

一个面向 Windows 的双网卡路由配置客户端。适用于“无线网卡访问外网、有线网卡访问公司内网”的场景，替代手写批处理脚本，让用户可以在图形界面中选择网卡、配置内网网关、管理公司网段，并指定某些域名或 IP 走内网。

## 功能特性

- 自动扫描本机 IPv4 网卡
- 自动识别无线网卡、有线网卡和连接状态
- 手动选择外网网卡和公司内网网卡
- 配置外网/内网网络优先级
- 配置公司内网网关
- 添加、删除公司内网网段
- 添加、删除指定域名或 IP
- 域名会先解析为 IPv4，再写入主机路由
- 内置“知网”目标组，覆盖常用 CNKI 入口、检索、登录、下载和资源域名
- 提供执行日志，方便排查路由写入结果
- 支持发布为单文件 Windows exe

## 适用场景

很多公司或校园网络会同时使用两张网卡：

- WLAN / Wi-Fi：访问 Internet
- Ethernet / 有线网卡：访问公司或校园内网

如果默认路由配置不当，可能出现外网访问失败、内网系统访问失败、知网下载失败等问题。本工具会将外网网卡设为更高优先级，同时把公司网段和指定域名/IP 指向内网网关。

## 默认配置

- 外网网卡优先级：`10`
- 公司内网网卡优先级：`50`
- 公司内网网关：`192.168.25.254`
- 默认公司网段：
  - `192.168.10.0 / 255.255.255.0`
  - `192.168.111.0 / 255.255.255.0`
  - `192.168.150.0 / 255.255.255.0`
  - `192.168.208.0 / 255.255.255.0`
- 默认指定目标：
  - `知网`

`知网` 会自动展开并解析多个常用 CNKI 域名，例如 `kns.cnki.net`、`bar.cnki.net`、`download.cnki.net`、`piccache.cnki.net` 等。

## 使用方式

1. 以管理员身份运行客户端。
2. 点击“重新扫描”，确认网卡列表正确。
3. 选择外网网卡，通常是 `WLAN` 或 `Wi-Fi`。
4. 选择公司内网网卡，通常是 `以太网`。
5. 按需修改内网网关、公司网段、指定域名/IP。
6. 如果配置了域名，先点击“解析目标”查看解析结果。
7. 点击“应用策略”。
8. 查看执行日志确认配置结果。

## 域名/IP 走内网

Windows 路由表最终按 IP 生效，不能直接按域名通配。因此本工具会先解析域名，再为解析出的 IPv4 地址添加 `255.255.255.255` 主机路由。

目标输入支持：

- 域名：`kns.cnki.net`
- 完整 URL：`https://kns.cnki.net/`
- 单个 IPv4：`121.194.4.10`
- 内置目标组：`知网`

如果某个网站下载失败，可以用浏览器开发者工具的 Network 面板找到实际请求域名，再添加到“指定域名/IP 走内网”。

## 开发运行

环境要求：

- Windows 10/11
- .NET 8 SDK

运行：

```powershell
cd .\NetworkRouterClient
dotnet run
```

## 发布 exe

发布为依赖本机 .NET Desktop Runtime 的单文件 exe：

```powershell
cd .\NetworkRouterClient
dotnet publish -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true
```

生成文件位于：

```text
NetworkRouterClient\bin\Release\net8.0-windows\win-x64\publish\NetworkRouterClient.exe
```

## 注意事项

- 修改网络优先级和写入永久路由需要管理员权限。
- 应用策略会修改 Windows 路由表，请确认网关和网卡选择正确。
- 域名解析结果可能会随网络环境变化，下载类站点尤其常见。
- 如果目标网站使用新的 CDN 或跳转域名，需要把实际域名添加到目标列表。
